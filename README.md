# Assignment 3

Campus Study Club is a responsive page made with HTML, CSS, and Bootstrap 5.3.8.

Open `index.html` in a browser. You need an internet connection to load Bootstrap from the CDN.

The Activities section uses CSS Grid. It shows one item per row below 768px, two from 768px, and three from 992px. The heading gets larger and the gaps get wider at 768px.

The other sections use Bootstrap. The session cards use `col-12 col-md-6 col-lg-4` for the same one, two, and three-column layout. In the Home section, `order-*` classes put the text above the image on small screens and to the right of it on large screens. The extra sentence uses `d-none d-md-block` to hide it below 768px. The menu and FAQ work through Bootstrap's JavaScript bundle.

The club and schedule are examples for this assignment.

The report and screenshots are in the `report` folder.
